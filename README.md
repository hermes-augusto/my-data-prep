# Data Warehouse - Streaming Case

## Descrição

Projeto de modelagem de dados com:

- OLTP normalizado
- Data Warehouse em Star Schema
- ETL com carga inicial e incremental
- SCD1 e SCD2
- Queries analíticas

---

## Pré-requisitos

- PostgreSQL acessível
- psql instalado
- Acesso ao banco
- Para configurações inicias acessar [repo do professor](https://github.com/fquintieri/my-data-prep) 

---

## Execução
- Executar o arquivo run_all.sh (Lembrar que a senha esta HARDCODED)
